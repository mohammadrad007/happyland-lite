درباره Happy Land Lite

یک فروشگاه اینترنتی مینیمال پوشاک — ساخته‌شده با HTML، CSS و JavaScript خالص و بک‌اند Node.js/Express. پروژه‌ی دانشگاهی با تمرکز بر تجربه‌ی کاربری، معماری ماژولار و کد تمیز.

🎓 پروژه دانشگاهی ⚡ Vanilla JS 🎨 Tailwind + CSS 🔧 Node.js + Express 🌗 دارک/لایت 🔐 پرداخت شبیه‌سازی

🎯 هدف پروژه

هدف این پروژه، پیاده‌سازی یک فروشگاه اینترنتی کامل با تمرکز بر مینیمالیسم، خوانایی کد، تجربه‌ی کاربری روان و معماری ماژولار بود. تمام مراحل یک خرید واقعی — از جستجوی محصول، انتخاب سایز، استفاده از کد تخفیف، تا پرداخت و پیگیری سفارش — شبیه‌سازی شده تا ساختار استاندارد یک فروشگاه e-commerce به‌طور کامل نمایش داده شود.

✨ ویژگی‌های اصلی

🔍

جستجوی زنده

جستجو در نام، توضیحات و دسته‌بندی با debounce و مرتب‌سازی هوشمند نتایج.

🎛

فیلتر و مرتب‌سازی

فیلتر دسته، بازه‌ی قیمت، فقط تخفیف‌دار و مرتب‌سازی (ارزان/گران/بیشترین تخفیف).

📄

Infinite Scroll

بارگذاری خودکار محصولات با اسکرول، با استفاده از IntersectionObserver.

📏

انتخاب سایز و تعداد

انتخاب سایز (S/M/L یا سنی) و تعداد قبل از افزودن به سبد، با cartId یکتا.

🛒

سبد خرید هوشمند

افزودن/حذف، تغییر تعداد با دکمه‌های +/–، پشتیبانی از چند سایز، ذخیره در localStorage.

🎟

کد تخفیف

اعتبارسنجی سمت بک‌اند، دو نوع تخفیف (درصدی/ثابت) با حداقل خرید و سقف.

❤

علاقه‌مندی‌ها

ذخیره‌ی محصولات موردعلاقه برای هر کاربر با اتصال به دیتابیس.

👤

احراز هویت + آواتار

ثبت‌نام با نشانگر قدرت رمز، ورود، آواتار تعاملی با منوی کشویی.

💳

پرداخت هوشمند

درگاه شبیه‌سازی با تنظیمات از .env (always-success / random / manual).

📦

پیگیری سفارش

داشبورد، صفحه‌ی جزئیات با فاکتور و صفحه‌ی موفقیت پرداخت با انیمیشن تیک.

👀

تاریخچه مشاهده

نمایش «اخیراً دیدید» با ذخیره‌سازی محلی و اسلایدر افقی.

🌗

تم دارک و لایت

انتخاب کاربر با ذخیره‌سازی و احترام به prefers-color-scheme سیستم.

📱

ریسپانسیو کامل

طراحی سازگار با موبایل، تبلت و دسکتاپ با Grid و Media Queries.

🗺

نقشه تعاملی

نقشه‌ی Leaflet در صفحه‌ی تماس با مارکر و پاپ‌آپ موقعیت فروشگاه.

🎤

Breadcrumb

نمایش مسیر صفحه با آیکون و لینک بازگشت، در همه‌ی صفحات.

💫 تجربه‌ی کاربری

  • Skeleton Loader: کارت‌های خاکستری shimmer قبل از لود محصولات
  • Infinite Scroll: بارگذاری خودکار ۸ محصول بعدی با اسکرول
  • انیمیشن پرواز به سبد: حرکت عکس محصول به سمت آیکون سبد با Bezier
  • Toast Notification: پیام‌های بازخورد در گوشه‌ی صفحه
  • انیمیشن موفقیت: تیک سبز کشیده‌شده بعد از پرداخت
  • حالت خالی: انیمیشن SVG سبد خرید خالی با جرقه‌های چشمک‌زن
  • انیمیشن تغییر تعداد: پالس روی عدد سبد هنگام + یا –
  • صفحه‌ی لاگین/ثبت‌نام مدرن: دو ستونه با بخش تصویری گرادیانت
  • صفحه‌ی پرداخت: کارت درگاه با اسپینر و حالت موفق/ناموفق
  • Accessibility: aria-label، prefers-reduced-motion، keyboard navigation

🏗 معماری پروژه

پروژه به‌صورت ماژولار طراحی شده — هر فایل JavaScript یک مسئولیت مشخص دارد. این کار باعث خوانایی بهتر، نگهداری آسان‌تر و امکان تست جداگانه‌ی هر بخش می‌شود.

API Layer تمام ارتباط با بک‌اند در فایل api.js متمرکز شده — ۱۴ endpoint
State سبد خرید، recently و تم در localStorage؛ سفارشات در بک‌اند
Components هدر، فوتر، سبد خرید و Breadcrumb ماژولار روی همه‌ی صفحه‌ها تزریق می‌شوند
Style CSS در ۴ فایل جدا (base, layout, components, utilities) + Tailwind محلی
Cart هر محصول با cartId یکتا (ترکیب id + size) — پشتیبانی از چند سایز
Config تنظیمات پرداخت از .env خوانده می‌شود (mode, delay, messages)

🔌 API Endpoints

متد مسیر توضیح
GET /api/products لیست محصولات با فیلتر، جستجو، صفحه‌بندی
GET /api/products/:id جزئیات یک محصول
GET /api/deals پیشنهادات ویژه (تخفیف بالای ۵۰٪)
POST /api/login ورود کاربر
POST /api/register ثبت‌نام کاربر جدید
GET /api/favorites لیست علاقه‌مندی‌ها
POST /api/favorites افزودن به علاقه‌مندی‌ها
DELETE /api/favorites/:id حذف از علاقه‌مندی‌ها
POST /api/coupons/validate اعتبارسنجی کد تخفیف
GET /api/orders لیست سفارش‌ها
GET /api/orders/:id جزئیات یک سفارش
POST /api/orders ساخت سفارش جدید
POST /api/payment پرداخت سفارش (تنظیمات از .env)
GET /api/config/payment خواندن تنظیمات پرداخت (اختیاری)

🎤 نکات کلیدی برای ارائه

این بخش مخصوص خودت است — توی صفحه می‌توانی نگهش داری یا حذفش کنی.

۱

معماری ماژولار

هر فایل JS یک مسئولیت دارد (api.js, cart.js, ui.js). کد قابل نگهداری و تست است.

۲

بدون فریمورک

همه‌چیز با Vanilla JS و ES Modules — بدون React یا Vue. درک عمیق‌تر از JavaScript.

۳

REST API واقعی

بک‌اند Express با ۱۴ endpoint، پشتیبانی از query params و مدیریت خطا.

۴

UX حرفه‌ای

Skeleton loading، انیمیشن پرواز، تیک موفقیت، سبد خالی متحرک، صفحه‌ی لاگین/پرداخت مدرن.

۵

CSS ماژولار

۴ فایل جدا برای مسئولیت‌های مختلف + CSS Variables برای تم. Tailwind محلی، نه CDN.

۶

امنیت و اعتبارسنجی

اعتبارسنجی سمت سرور، چک دسترسی به سفارش (فقط صاحب سفارش) و جلوگیری از XSS.

۷

پشتیبانی از سایز

cartId یکتا (id + size) — کاربر می‌تواند یک محصول را با دو سایز مختلف داشته باشد.

۸

تنظیمات از .env

PAYMENT_MODE، PAYMENT_DELAY و پیام‌ها از .env خوانده می‌شوند — بدون تغییر کد.

⚠️ محدودیت‌های پروژه

  • داده‌ها در فایل‌های JSON ذخیره می‌شوند، نه دیتابیس واقعی (MongoDB/PostgreSQL)
  • رمز عبور plain text — برای پروداکشن نیاز به bcrypt دارد
  • توکن احراز هویت دمو است، JWT واقعی پیاده نشده
  • درگاه پرداخت شبیه‌سازی‌شده — پول واقعی جابه‌جا نمی‌شود
  • فرم تماس با ما فقط شبیه‌سازی شده — ارسال واقعی ایمیل انجام نمی‌شود
  • بدون تست خودکار (unit test / integration test)

نکته برای ارائه: اگر استاد پرسید «چرا JWT نه؟» بگو «به‌دلیل محدودیت زمان پروژه، احراز هویت ساده پیاده شد ولی ساختار کد آماده‌ی ارتقا به JWT است.»
